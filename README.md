# EEAT-аудит — деплой на сайт

## Что это
- `api/audit.js` — серверная функция: сама читает сайт (без CORS-ограничений браузера), сама зовёт Claude API с ключом, который никогда не попадает в браузер, сама разбирает JSON-LD на наличие MedicalOrganization/Physician/MedicalProcedure (чистый код, без LLM и без сторонних API).
- `public/index.html` — страница с формой, тот же дизайн, что в демо.
- Читает главную + до 2 связанных страниц (врачи/о клинике), если находит на них ссылки.

## Деплой (Vercel, ~10 минут)

1. Получите ключ Claude API на platform.claude.com (если ещё нет).
2. Загрузите эту папку в GitHub-репозиторий (или разверните напрямую через `vercel` CLI без гита — `npm i -g vercel`, затем `vercel` из этой папки).
3. На vercel.com → New Project → импортируйте репозиторий.
4. В Settings → Environment Variables добавьте `ANTHROPIC_API_KEY` со значением ключа.
5. Deploy. Vercel сам распознаёт `api/` как функции и `public/` как статику — доп. конфиг не нужен.
6. Получите адрес вида `https://eeat-audit-app.vercel.app`.

## Встройка на сайт

Проще всего — iframe, работает независимо от движка основного сайта:

```html
<iframe
  src="https://eeat-audit-app.vercel.app"
  width="100%"
  height="900"
  style="border:none;"
  title="EEAT-аудит клиники">
</iframe>
```

CORS тут не мешает: iframe целиком грузится с домена Vercel, обращение к `/api/audit` внутри него — тот же домен.

## На заметку

- Каждый запуск — это один вызов Claude API за ваш счёт. Прежде чем давать публичную ссылку широко, стоит добавить простую защиту от накрутки (например, капчу или лимит запросов с одного IP) — это в бэклог, не блокер для первого теста.
